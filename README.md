# Lord of the Flies Clash

A pixel-art 1v1 fighting game starring the boys from *Lord of the Flies*. It is built on the Anime Clash engine and runs in the browser from a single file with no build step. Open `index.html` in a browser and click the game once so it receives key presses.

## Modes

- **1 – VS CPU:** choose a difficulty (Easy, Medium, Hard or Super Hard), then pick your fighter and the CPU's.
- **2 – 2 Players:** two players share one keyboard (or one touch screen).

Matches are best of 3 rounds with a 99-second timer, fought on four island stages: the beach, Castle Rock, the jungle and the signal fire mountain.

## Controls

| | Player 1 | Player 2 |
|---|---|---|
| Move / jump | `W A S D` | Arrow keys |
| Signature | `1` | `6` (or Numpad 1) |
| Special | `2` | `7` (or Numpad 2) |
| Super | `3` | `8` (or Numpad 3) |
| Light | `4` | `9` (or Numpad 4) |
| Heavy | `5` | `0` (or Numpad 5) |
| Throw | `4` + `5` | `9` + `0` |
| Lock in fighter | `1`, `Enter` or `Space` | `6` or `Numpad 1` |

Hold the direction away from your opponent to block. Supers need a full power bar. `P` pauses and shows both move lists, `M` mutes and `Esc` goes back.

## Fighters

| Fighter | Signature (1) | Special (2) | Super (3) |
|---|---|---|---|
| Ralph – The Chief | Leader Attack | Logic Attack | Conch Blow (sound wave attack) |
| Jack – The Hunter | Spear Poke | Pig Hunt | Kill the Beast (3-hit chant combo) |
| Piggy – The Thinker | Brain Wave | Asthma Attack | Spec Fire |
| Simon – The Listener | Fairness Strike | Fly Barrage | Listener Attack |

Each fighter also has a light and heavy attack and a throw. Character select shows each boy's description and move list.
